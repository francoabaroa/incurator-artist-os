# EPK / Press Kit

Strategic frameworks for creating and maintaining professional artist portfolios.

## When to Use This Skill

- Creating an Electronic Press Kit (EPK) from scratch
- Updating existing EPK with new materials
- Creating a one-sheet for specific outreach
- Preparing materials for press, booking, labels, or sync
- Understanding what different gatekeepers need to see

## What Is an EPK?

An EPK (Electronic Press Kit) is your professional portfolio—the "resume" of your music career. It contains everything a gatekeeper (booker, journalist, label, sync supervisor) needs to evaluate and write about you.

**The purpose is simple:** Make it EASY for people to say yes.

## EPK Triage

### Do You Need an EPK?

| Situation | Need Level | Why |
|-----------|------------|-----|
| Pitching to venues | Essential | Bookers won't respond without materials |
| Seeking press coverage | Essential | Journalists need ready-to-use assets |
| Approaching labels | Essential | A&R needs to evaluate you quickly |
| Sync licensing submissions | Essential | Sync supervisors need clean info |
| Just releasing music | Optional | Focus on music first, EPK later |

### What Stage Is Your EPK?

| Stage | Signs | Action |
|-------|-------|--------|
| **None** | No organized materials | Build from scratch |
| **Scattered** | Assets exist but not compiled | Organize and consolidate |
| **Outdated** | EPK exists but old info | Update with current materials |
| **Complete** | Current and comprehensive | Maintain, adapt for context |

## EPK Components

### Essential Components (Must Have)

| Component | What It Is | Format |
|-----------|------------|--------|
| **Artist Bio** | Short (100 words), Medium (200), Long (500) | Text (.docx, .txt) |
| **Press Photos** | 3-5 high-resolution images | JPG, 300 DPI, horizontal + vertical |
| **Music Links** | Streaming links, private previews | Spotify, SoundCloud, private links |
| **Contact Info** | Booking, press, management | Email, phone |
| **Social Links** | Active platforms | Instagram, TikTok, etc. |

### Recommended Components (Should Have)

| Component | What It Is | Format |
|-----------|------------|--------|
| **One-Sheet** | Single-page summary (see below) | PDF |
| **Press Quotes** | Notable reviews or blurbs | Text |
| **Live Video** | Performance footage | YouTube/Vimeo link |
| **Tech Rider** | Stage requirements | PDF |
| **Stage Plot** | Visual setup diagram | PDF or image |
| **Tour History** | Notable shows played | List |

### Optional Components (Nice to Have)

| Component | What It Is | When Needed |
|-----------|------------|-------------|
| **Music Video** | Official video content | If you have one |
| **Lyrics** | Written lyrics for press | For press coverage |
| **Cover Art** | High-res artwork | For editorial use |
| **Logo** | Artist logo files | If you have branding |
| **Stats Sheet** | Streams, followers, growth | For labels/booking |
| **Testimonials** | Industry endorsements | If notable |

## EPK Versions by Purpose

Different gatekeepers need different information:

### Press EPK

**Primary goal:** Make it easy to write about you

**Emphasize:**
- Multiple bio lengths (they'll pick what fits)
- Press quotes from similar outlets
- Unique story angles
- High-res photos with clear credits
- Music streaming links (embed-friendly)
- Interview availability

**De-emphasize:**
- Tech rider (irrelevant)
- Booking info (different inquiry)
- Stats (unless impressive)

### Booking EPK

**Primary goal:** Prove you can draw and perform

**Emphasize:**
- Draw history (ticket sales, numbers)
- Live performance video
- Tech rider and stage plot
- Tour history (similar venues)
- Streaming stats (shows reach)
- Merch photos (if you sell at shows)

**De-emphasize:**
- Long bio (short version only)
- Press quotes (unless venue-relevant)
- Multiple photos (1-2 strong ones)

### Label/A&R EPK

**Primary goal:** Show growth potential

**Emphasize:**
- Streaming stats with growth trajectory
- Engagement metrics (saves, playlist adds)
- Social following with engagement rate
- Press coverage (buzz indicator)
- Live draw (touring potential)
- Story/narrative (what makes you investable)

**De-emphasize:**
- Tech rider (premature)
- Tour history (unless notable)

### Sync EPK

**Primary goal:** Easy to license

**Emphasize:**
- Clean ownership info (who controls masters, publishing)
- Instrumental versions available
- Stems availability
- Genre/mood tags
- Lyrics (for content matching)
- Contact for licensing inquiries

**De-emphasize:**
- Live video (irrelevant)
- Tour history (irrelevant)
- Social stats (less relevant)

## The One-Sheet

A one-sheet is a single-page summary—your EPK condensed to its essence.

### One-Sheet Structure

```
[HEADER]
Artist Name / Logo
Genre | Location | Contact

[HERO SECTION]
Best press photo (takes up 30-40% of page)

[BIO]
100-150 words maximum
Hook in first sentence

[QUICK STATS]
• [X] Monthly Listeners
• [X] Social Followers
• [Notable Achievement]
• [Notable Achievement]

[MUSIC]
Latest Release: "[Title]" - [Streaming Link]
[1-2 more tracks if relevant]

[PRESS QUOTES]
"[Quote]" - [Outlet]
"[Quote]" - [Outlet]

[LINKS]
Spotify | Instagram | Website

[CONTACT]
Booking: [email]
Press: [email]
Management: [email]

[FOOTER]
Press assets: [Link to full EPK]
```

See `assets/one-sheet-template.md` for full template.

### One-Sheet Best Practices

- **One page only** — If it doesn't fit, cut content
- **Visual first** — Design matters; this is a first impression
- **Scannable** — Clear hierarchy, not walls of text
- **Updated** — Current photo, current stats, current release
- **PDF format** — Universal, preserves formatting
- **Under 5MB** — Email-friendly file size

## Hosting Your EPK

### Hosting Options

| Option | Pros | Cons | Best For |
|--------|------|------|----------|
| **Website page** | Professional, always updated | Requires website | Established artists |
| **Dropbox/Google Drive** | Free, easy to update | Less professional look | Budget-conscious |
| **EPK platforms** (Sonicbids, ReverbNation) | Industry-standard | Paid, outdated feel | Festival submissions |
| **Notion page** | Clean, free, easy | Less common | Tech-savvy artists |
| **LinkTree landing** | Quick, accessible | Limited depth | Social-first artists |

## Writing Your Bio

### Bio Lengths

| Length | Word Count | Use Case |
|--------|------------|----------|
| **Tagline** | 10-15 words | Social profiles, quick intros |
| **Short** | 100 words | Playlists, social bios |
| **Medium** | 200-250 words | Press, general use |
| **Long** | 400-500 words | Features, in-depth coverage |

### Bio Structure

**Paragraph 1:** Hook + who you are + what you sound like

**Paragraph 2:** Journey/story + key moments + credibility

**Paragraph 3:** Current/next + what's happening now

### Bio Writing Tips

**DO:**
- Write in third person ("Luna Ray makes...")
- Lead with something interesting (not "Luna Ray is an artist from...")
- Include specific details (not generic descriptions)
- Mention comparable artists if helpful
- Include recent achievements

**DON'T:**
- Use first person ("I am...")
- Start with your birthplace/childhood
- Use superlatives without proof ("the best...")
- Include every achievement ever
- Write more than 500 words

### Bio Template

```
[HOOK + SOUND]
[Artist Name] is a [genre] artist from [Location] whose music [emotional descriptor]. 
Blending [influence 1] with [influence 2], [his/her/their] sound has been described as 
"[quote or comparison]."

[STORY + CREDIBILITY]
[Narrative element: origin story, key moment, unique background]. Since [debut], 
[Artist Name] has [achievement 1], [achievement 2], and [achievement 3]. 
[His/Her/Their] music has been featured in [notable placement if any].

[CURRENT + NEXT]
[His/Her/Their] latest [single/album], "[Title]," [brief description]. 
[What's coming next or current focus].
```

## Update Cadence

### When to Update Your EPK

| Trigger | What to Update |
|---------|----------------|
| New release | Add to music section, update bio |
| New press coverage | Add quotes, update clippings |
| New photos | Replace old photos |
| Major milestone | Update stats, add to achievements |
| Annual review | Full audit of all materials |

### Quarterly Review Checklist

- [ ] Bio reflects current status
- [ ] Photos are from within the last 12 months
- [ ] Music links all work
- [ ] Stats are current (within 3 months)
- [ ] Press quotes are recent
- [ ] Contact info is correct
- [ ] All links work

## Anti-Patterns: What NOT to Do

❌ **Outdated materials** — Old photos, old stats, old bio
❌ **Too much content** — Keep it focused and scannable
❌ **Low-res photos** — Unusable for print/editorial
❌ **Broken links** — Test everything before sending
❌ **Generic bio** — "Passionate musician who loves music" says nothing
❌ **No contact info** — How will they reach you?
❌ **Sending everything** — Customize for the recipient
❌ **PDF bio only** — Include .txt for easy copy/paste
❌ **No photo credits** — Include photographer credit

## Workflow

1. **Assessment**
   - Do they have an EPK? What stage?
   - What's the purpose? (Press, booking, label, sync)
   - What materials exist?

2. **Gap Analysis**
   - What's missing from essential components?
   - What needs updating?
   - What's the priority?

3. **Creation/Update**
   - Build or update components
   - Organize according to structure
   - Create one-sheet if needed

4. **Quality Check**
   - All links work
   - All files downloadable
   - All info current

5. **Update Workspace**
   - Add EPK tasks to `tasks/backlog.json`
   - Note EPK location for future reference
