# EPK Component Checklist

Use this checklist to track your EPK components.

---

## Essential Components

### Bios
- [ ] Tagline (10-15 words)
- [ ] Short bio (100 words)
- [ ] Medium bio (200-250 words)
- [ ] Long bio (400-500 words)
- [ ] All bios in .txt format (for easy copy/paste)
- [ ] All bios in .docx format (for editing)
- [ ] Written in third person
- [ ] Updated within last 6 months

### Photos
- [ ] Minimum 3 high-resolution photos
- [ ] At least 1 horizontal (landscape) orientation
- [ ] At least 1 vertical (portrait) orientation
- [ ] At least 1 square option
- [ ] Resolution: 300 DPI / 3000+ pixels on long edge
- [ ] File format: JPG
- [ ] Photographer credited
- [ ] Taken within last 12 months
- [ ] Web-optimized versions (72 DPI) also included

### Music Links
- [ ] Spotify artist profile link
- [ ] Apple Music artist profile link
- [ ] Latest release direct link
- [ ] Private/unreleased preview links (if applicable)
- [ ] All links tested and working

### Contact Information
- [ ] Booking email
- [ ] Press/media email
- [ ] Management email (if applicable)
- [ ] Phone number (optional but recommended)
- [ ] Clear indication of who handles what

### Social Links
- [ ] Instagram
- [ ] TikTok
- [ ] YouTube
- [ ] Twitter/X (if active)
- [ ] Website
- [ ] All links tested and working

---

## Recommended Components

### One-Sheet
- [ ] Created as PDF
- [ ] Single page only
- [ ] Under 5MB file size
- [ ] Includes hero photo
- [ ] Includes short bio
- [ ] Includes key stats
- [ ] Includes latest release
- [ ] Includes contact info
- [ ] Updated with current info

### Press Coverage
- [ ] Press quotes compiled
- [ ] Full articles saved as PDFs
- [ ] Links to online coverage
- [ ] Notable quotes highlighted
- [ ] Recent coverage prioritized

### Live Video
- [ ] At least 1 full performance video
- [ ] Good audio quality
- [ ] Good video quality
- [ ] Hosted on YouTube or Vimeo
- [ ] Unlisted option for exclusive sharing

### Tech Rider (for booking)
- [ ] Input list (channels needed)
- [ ] Backline requirements
- [ ] Monitor preferences
- [ ] Special requirements
- [ ] Band/artist count
- [ ] Contact for day-of questions

### Stage Plot (for booking)
- [ ] Visual diagram of setup
- [ ] Clear labels for each position
- [ ] Input/monitor positions marked
- [ ] PDF or image format

### Tour History (for booking)
- [ ] Notable venues played
- [ ] Festival appearances
- [ ] Tour dates with headliners opened for
- [ ] Recent dates prioritized

---

## Optional Components

### Music Video
- [ ] Official music video link(s)
- [ ] Hosted on YouTube (preferred)
- [ ] Unlisted option available

### Lyrics
- [ ] Lyrics for all released songs
- [ ] Formatted clearly
- [ ] Available in .txt or .docx

### Cover Art
- [ ] High-resolution artwork (3000x3000)
- [ ] All release artwork
- [ ] Credits included

### Logo
- [ ] Vector format (SVG, AI, EPS)
- [ ] PNG with transparency
- [ ] Multiple color versions (dark/light)

### Stats Sheet
- [ ] Monthly listeners (Spotify)
- [ ] Total streams
- [ ] Social followers by platform
- [ ] Engagement rate
- [ ] Growth metrics (month-over-month or year-over-year)
- [ ] Date of stats (for freshness)

### Testimonials
- [ ] Industry quotes
- [ ] Artist endorsements
- [ ] Fan testimonials (if notable)

---

## Quality Checks

### All Components
- [ ] All files open correctly
- [ ] All links work
- [ ] All information is current
- [ ] No typos or errors
- [ ] Consistent branding/formatting
- [ ] File sizes appropriate for email

### Before Sending
- [ ] Customized for recipient type (press/booking/label/sync)
- [ ] Only relevant materials included
- [ ] Clear file naming convention
- [ ] Tested by downloading yourself
- [ ] Links don't require login/permission

---

## Update Schedule

### After Every Release
- [ ] Update bio with new release
- [ ] Add streaming links
- [ ] Update stats
- [ ] Add new cover art

### Quarterly
- [ ] Full link audit
- [ ] Stats refresh
- [ ] Press quote update
- [ ] Photo freshness check

### Annually
- [ ] Full EPK audit
- [ ] New photos if needed
- [ ] Bio rewrite consideration
- [ ] Structure/hosting review
