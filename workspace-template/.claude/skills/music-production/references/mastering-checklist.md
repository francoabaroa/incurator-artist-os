# Pre-Mastering Checklist

Ensure your track is ready for the mastering engineer or automated service.

## 1. Technical Prep
- [ ] Sample Rate: Same as recording (usually 44.1kHz or 48kHz).
- [ ] Bit Depth: 24-bit or 32-bit float.
- [ ] File Format: Uncompressed WAV or AIFF.
- [ ] No Clipping: Peak levels around -3dB to -6dB.

## 2. Bus Processing
- [ ] Remove all heavy limiters or "loudness" plugins from the master bus.
- [ ] Keep mix-bus compression minimal (only for vibe).
- [ ] Check for DC offset (most DAWs do this automatically on export).

## 3. Top & Tail
- [ ] Leave 1-2 bars of silence at the beginning (prevents cut-offs).
- [ ] Ensure the tail (reverb fade) is not cut off.

## 4. Metadata for Final
- [ ] Title: {Final Song Title}
- [ ] Artist: {Main Artist Name}
- [ ] Album: {Project Title or Single}
- [ ] ISRC: {Include if known}
