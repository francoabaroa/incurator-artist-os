# Detailed Release Checklist

## Assets
- WAV masters (24-bit, 44.1kHz or higher)
- Instrumentals (optional)
- Clean versions (if needed)
- Cover art (3000x3000 px, RGB)

## Metadata
- Final track titles
- Writer and producer credits
- Explicit flag
- ISRC/UPC (leave null until assigned)
- Genre and subgenre

## Delivery
- Distributor upload complete
- Release date and time confirmed
- Pre-save link created

## Marketing
- Teaser content scheduled
- Press kit updated
- Playlist pitch submitted
