# Metadata Checklist

Ensure the following fields are collected before attempting distribution. Use `null` if any optional field is unknown.

## Essential Track Info
- **Song Title**: Final name.
- **Primary Artist**: Main artist name.
- **Featured Artists**: List of guest artists.
- **Genre**: Main genre (e.g., Hip Hop).
- **Sub-genre**: Secondary genre (e.g., Trap).
- **Language**: Language of the lyrics.
- **Explicit Content**: Yes/No.

## Publishing & Credits
- **Songwriters**: Full legal names of all lyricists/composers.
- **Producers**: Full legal names of producers.
- **Publisher**: Entity that controls the publishing rights.

## Technical Identifiers
- **ISRC**: Assigned by the distributor (e.g., QM-XXX-24-XXXXX).
- **UPC**: Assigned by the distributor for the release bundle.
- **Release Date**: Future date (allow 3-4 weeks for pitching).

## Audio Specs
- **Format**: WAV only.
- **Bit Depth**: 16-bit or 24-bit.
- **Sample Rate**: 44.1kHz (minimum).

## Artwork Specs
- **Dimensions**: 3000 x 3000 pixels (exact square).
- **Format**: JPG or TIFF.
- **Color Mode**: RGB.
- **Text**: Must exactly match the artist and title metadata. No URLs, logos, or extra text.
